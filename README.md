# 🎬 Netflix Movie Analysis

## About the Project

This project analyzes Netflix movies and TV shows using **Python in Google Colab**. It explores content trends, movie and TV show distribution, ratings, release years, countries, and genres through data analysis and visualization.

## Features

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Movie and TV show analysis
* Genre analysis
* Country-wise content analysis
* Data visualization
* Business insights

## Technologies Used

* Google Colab
* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Dataset

The project uses the **Netflix Movies and TV Shows Dataset**, which contains information such as:

* Show ID
* Title
* Type (Movie/TV Show)
* Director
* Cast
* Country
* Release Year
* Rating
* Duration
* Genre

## Project Workflow

1. Import the dataset into Google Colab
2. Clean and preprocess the data
3. Perform Exploratory Data Analysis (EDA)
4. Analyze movies and TV shows
5. Create visualizations
6. Generate insights

## Results

The analysis provides insights into:

* Distribution of Movies and TV Shows
* Most common genres
* Content by country
* Release year trends
* Netflix content patterns
